# Copilot Skill

This workspace contains a starter skill scaffold for building a simple assistant skill.

## Files

- `src/index.js` - CLI entrypoint that sends text input to the skill.
- `src/skill.js` - Skill logic and exports.
- `test/test.js` - Basic test to validate skill behavior.

## Usage

1. Install dependencies if needed (none required for this starter).
2. Run the skill:
   ```bash
   npm start -- "Hello skill"
   ```
3. Run the test:
   ```bash
   npm test
   ```

## Next steps

Customize `src/skill.js` to implement the behavior you want for the skill.
